# WAKANDABOY100 Artist Portfolio

Official website for **Collins Wewa / WAKANDABOY100**, live at <https://wakandaboy100.com>.

Collins Wewa is an independent artist and performer working across music, dance, comedy and video. The site is his home base: music videos, streaming links, booking requests, and The Ultimate Cardio merch collection sold through his Fourthwall shop. It is a static site on GitHub Pages, generated by a small Python script and verified before every deploy.

## Routes

| URL | Page |
| --- | --- |
| `/` | Brand home: merch campaign, artist intro, selected videos and streaming links |
| `/about/` | Collins Wewa biography and entity page |
| `/videos/` | Music video, performance and comedy catalog |
| `/music/` | Verified streaming profiles |
| `/booking/` | Private-event and performance requests (currently through Instagram DM) |
| `/merch/the-ultimate-cardio/` | Full nine-style collection page with links to the official shop |

Public navigation uses real directory-index routes. There is no HashRouter; the only fragment is the accessibility skip link to `#main`. `404.html` is the Pages not-found page.

## Build and preview

Requires Python 3 (CI uses 3.12).

```bash
python3 scripts/build_site.py    # regenerate the six route pages
python3 scripts/verify_site.py   # check routes, metadata, links and assets
python3 -m http.server 8000      # preview at http://localhost:8000
```

The six route pages are generated. Edit `scripts/build_site.py` (page templates, navigation, social links, structured data) or the JSON in `content/`, then rebuild. Hand edits to those `index.html` files are overwritten on the next build, including the one CI runs before every deploy. `404.html`, `style.css`, `script.js` and `sitemap.xml` are edited directly.

`verify_site.py` fails on:

- missing routes or local assets, and broken internal links
- title and description length, a single H1, canonical URLs and valid JSON-LD
- leftover Design Component runtime markers or prototype files
- old Shopify or Fourthwall store hosts, and shop links not listed in `content/merch.json`
- merch prices and product URLs that don't match `content/merch.json`
- public fragment navigation, sitemap drift, and missing entity terms

```text
├── assets/fonts/          # Anton and Barlow Condensed with their OFL licenses
├── scripts/               # build_site.py, verify_site.py, add_media.py
├── sitemap.xml, robots.txt, CNAME
└── DESIGN.md, DESIGN-DIRECTION.md, OPEN_DESIGN.md           # design contract
```

## Adding public media

Keep videos on Instagram or YouTube and add them to the website catalog with:

```bash
python3 scripts/add_media.py \
  --category comedy \
  --title "Public clip title" \
  --platform "Instagram Reel" \
  --url "https://www.instagram.com/reel/.../" \
  --description "Short public description."
```

The helper downloads the platform's public cover image, creates a landscape website card, updates `content/media.json`, rebuilds the site and runs verification. It does not download or republish the video. It needs `yt-dlp` and Pillow, and it calls `python` for the rebuild step, so that command must be on your `PATH`.

## Brand and commerce

- Approved dancer mark: `assets/images/wakandaboy100-dancer.svg`
- Approved shirt reference derivative: `assets/images/the-ultimate-cardio-shirt.webp`
- Visual system: athletic heather grey, ink black, paper white; Anton and Barlow Condensed
- Official shop collection: `https://shop.wakandaboy100.com/collections/all`
- `content/merch.json` holds the nine approved product URLs, names, prices, color lists and official product-render images.
- Starting prices run from $29 to $62, with size-tier increases on applicable products. Website copy and metadata must match Fourthwall before deployment.
- Campaign and lifestyle images in `assets/images/ultimate-cardio-v2/` are editorial. Product cards use the official storefront renders so shoppers can tell campaign imagery from the actual products.
- Do not publish placeholder products, invented prices, unsupported biography claims, the old `collins-wewa-shop.fourthwall.com` shop, or shop links outside `content/merch.json`.

See `DESIGN.md`, `DESIGN-DIRECTION.md` and `OPEN_DESIGN.md` for the design contract.

## Deployment

`.github/workflows/static.yml` runs on every push to `main` (or manually): it rebuilds the pages, runs `verify_site.py`, and deploys the repository to GitHub Pages only if verification passes. `CNAME` points Pages at `wakandaboy100.com`.
